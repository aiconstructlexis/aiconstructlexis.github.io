# Unnatural language comprehension
**Type:** Construct  
**Supporting papers:** 1  
**Also known as:** Contextual meaning inference, Keyword organization inference  

## State of the Field

The latent ability of an LLM to derive meaning from syntactically noisy, human-incomprehensible text while still using it to answer questions or reconstruct natural language.

## Sources

**Unnatural language comprehension** (1 paper: [Unnatural Languages Are Not Bugs but Features for LLMs](https://raw.githubusercontent.com/mlresearch/v267/main/assets/duan25c/duan25c.pdf))
> The latent ability of an LLM to derive meaning from syntactically noisy, human-incomprehensible text while still using it to answer questions or reconstruct natural language.

**Contextual meaning inference** (1 paper: [Unnatural Languages Are Not Bugs but Features for LLMs](https://raw.githubusercontent.com/mlresearch/v267/main/assets/duan25c/duan25c.pdf))
> The latent ability of LLMs to reconstruct the correct semantic organization of keywords from disordered, unnatural inputs by leveraging contextual cues from subsequent natural language questions.

**Keyword organization inference** (1 paper: [Unnatural Languages Are Not Bugs but Features for LLMs](https://raw.githubusercontent.com/mlresearch/v267/main/assets/duan25c/duan25c.pdf))
> The latent ability to infer the correct semantic and syntactic arrangement of keywords that have been extracted from a disordered or noisy input.
