# Type consistency
**Type:** Construct  
**Supporting papers:** 2  
**Also known as:** Repository-level consistency  

## State of the Field

The degree to which the type annotations generated by a model are coherent and free of contradictions when analyzed across an entire codebase.

## Sources

**Type consistency** (1 paper: [TypyBench: Evaluating LLM Type Inference for Untyped Python Repositories](https://raw.githubusercontent.com/mlresearch/v267/main/assets/dong25l/dong25l.pdf))
> The degree to which the type annotations generated by a model are coherent and free of contradictions when analyzed across an entire codebase.

**Repository-level consistency** (1 paper: [TypyBench: Evaluating LLM Type Inference for Untyped Python Repositories](https://raw.githubusercontent.com/mlresearch/v267/main/assets/dong25l/dong25l.pdf))
> The degree to which inferred type annotations form a globally coherent system across an entire codebase, ensuring compatibility across function calls and module boundaries.
