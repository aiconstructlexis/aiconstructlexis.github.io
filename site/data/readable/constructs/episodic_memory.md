# Episodic memory
**Type:** Construct  
**Supporting papers:** 7  

## State of the Field

**Space of definitions.** Across the definitions, episodic memory is consistently framed as access to specific past episodes rather than general knowledge. Some papers describe it at the model level as storage and retrieval of sequence-specific information, independent of generalized or natural language knowledge, while others emphasize recall of events grounded in time and space or of past user interactions and autobiographical experiences. The main variation is whether the construct is phrased as a storage and retrieval capacity or in more human-like autobiographical terms.

**Space of facets.** The clearest systematization is a contrast with semantic memory or generalized world knowledge: episodic memory is reserved for details of specific events, personal experiences, or sequence-specific information. Some authors also use the term for a memory mechanism, with embeddings or recurrent state described as serving as episodic memory that passes information between time steps, while others use the same term for a latent ability to recall specific experiences.

**Space of measurement.** In the linked operationalizations, no measurement instrument is attached to episodic memory, and no linked construct is recorded. One behavioral indicator is linked, Event segmentation, but it appears through a related link rather than a direct measured_by relation. The papers instead describe the construct through behaviors such as storing sequence-specific information across time steps, recalling events grounded in time and space, and recalling past user interactions, which matches how they define it.

**Links.** The only reported link is that episodic memory is related to Event segmentation. In that account, episodic memory is discussed in terms of how experiences are segmented into events. No causal or correlational relationships are reported.
