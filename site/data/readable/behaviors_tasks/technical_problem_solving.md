# Technical problem solving
**Type:** Behavioral indicator  
**Supporting papers:** 3  

## State of the Field

**Space of definitions.** Across the surveyed work, the prevailing usage treats technical problem solving as the behavior of generating answers to well-defined technical queries. The definitions align closely: one describes it as answering well-defined technical queries, while another frames it as answering questions that require specialized technical knowledge and problem-solving skills.

**Variants.** Variation is limited in the descriptions. Papers alternate between calling the items well-defined technical problem-solving queries and technical problem-solving questions, and one description emphasizes that these questions require specialized technical knowledge and problem-solving skills.

**Space of elicitation and scores.** Papers link it to one measurement instrument, Arena-Hard. They describe Arena-Hard as a benchmark or dataset made up of well-defined technical problem-solving queries, including descriptions that it builds on MT-Bench and is designed to test more advanced capabilities.

**What it is taken as evidence of.** At the construct level, the only linked construct is Error recovery. One paper claims a causal relationship from technical problem solving to Error recovery, stating that successful out-of-sync recoveries hinge not only on agents' technical problem-solving proficiency, but also on efficient cause analysis and effective collaboration capabilities.
