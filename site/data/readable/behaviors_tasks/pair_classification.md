# Pair classification
**Type:** Behavioral indicator  
**Supporting papers:** 3  

## State of the Field

**Space of definitions.** Across the cited definitions, pair classification is most commonly described as deciding whether two text inputs are semantically related or form a positive pair. The examples papers use are query-passage relevance and cases where two texts are paraphrases or otherwise have a specified relationship, so success is framed as correctly classifying the relation between the paired texts.

**Variants.** The examples named for this task include query-passage relevance, paraphrase judgments, and deciding whether a pair has some other specific relationship. Papers refer to the category as Pair Classification and, in one table, abbreviate it as PairClass.

**Space of elicitation and scores.** One measurement instrument is linked to it: MTEB, which one paper uses to evaluate Pair Classification as a task category. Separately, one paper reports pair classification with AP as the metric.

**What it is taken as evidence of.** No paper links it to a construct, so the cited work does not explicitly treat pair classification as evidence of a named construct.
