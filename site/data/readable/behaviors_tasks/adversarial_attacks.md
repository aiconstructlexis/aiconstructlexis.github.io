# Adversarial attacks
**Type:** Behavioral indicator  
**Supporting papers:** 6  
**Also known as:** Adversarial attack response, Trigger generation, Adversarial example generation, SQL injection  

## State of the Field

**Space of definitions.** Across the surveyed work, the prevailing usage treats adversarial attacks as observable tasks that craft perturbed or modified inputs to make a model produce a wrong outcome, most often misclassification or incorrect prediction. Other papers use the same umbrella for responses to jailbreak techniques or adversarial probes that induce forgotten knowledge, for producing hidden trigger tokens or patterns that can activate a backdoor in an evaluator, and for injecting malicious SQL payloads to manipulate queries or extract database data. Success is described in terms of the target effect, such as attacking a defense with perturbations of original images under a perturbation bound, fooling a model, eliciting forgotten knowledge, triggering the evaluator, or achieving database access.

**Variants.** The most common variant is adversarial example generation. Within that line, papers study image attacks that output perturbations of original images, NLI attacks that modify premise-hypothesis pairs by replacing selected words with antonyms to create lexically similar but semantically different sentences, and adversarial text generation that stays semantically similar to the original while causing incorrect predictions. Smaller lines of work describe adversarial attack response in unlearning settings, trigger generation for evaluator backdoors, and SQL injection against web applications.

**Space of elicitation and scores.** No measurement instrument is linked to it. Instead, papers usually operationalize the behavior through task-specific success criteria, such as whether perturbations make a model misclassify, whether modified text fools the model, whether jailbreak or adversarial probes induce forgotten knowledge, whether generated triggers must be fed to the evaluator, or whether a SQL payload extracts data or results in a successful login.

**What it is taken as evidence of.** The only linked construct is Robustness. One paper reports that adversarial attacks are related to Robustness, framing robustness as the ability to deliver correct results even for input manipulated by malicious actors and assessing it by seeking adversarial examples.
