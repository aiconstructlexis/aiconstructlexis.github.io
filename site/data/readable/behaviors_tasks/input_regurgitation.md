# Input regurgitation
**Type:** Behavioral indicator  
**Supporting papers:** 4  
**Also known as:** Verbatim text extraction, Context parroting  

## State of the Field

**Space of definitions.** Across the surveyed work, the prevailing usage treats this behavior as reproducing verbatim or near-verbatim parts of the provided or augmented context in the model output. Definitions also describe it as repeating or closely mimicking subsequences from the input context, and one recurring framing ties this reproduction to privacy leakage, with papers describing cases where "the model regurgitates them" or "leak[s] the augmented contexts." A smaller framing presents it as a task failure, where the model repeats or describes the input prompt rather than following the intended task or demonstrated pattern.

**Variants.** Papers study closely related variants under several names and settings. One line calls it verbatim text extraction, defined as producing retrieved datastore text nearly unchanged in the output, while another calls it context parroting, where a forecast is generated by repeating or closely mimicking subsequences from the input context. In cross-modal few-shot prompting, it is also described as prompt regurgitation, where the model "captions" or regurgitates the input instead of adhering to the demonstrated pattern.

**Space of elicitation and scores.** No measurement instrument is linked to it by the papers. The papers characterize it through behavioral descriptions such as verbatim or near-verbatim reproduction, close mimicry of context subsequences, or repeating the prompt instead of completing the intended task.

**What it is taken as evidence of.** Rather than converging on a single construct that this behavior reflects, papers link it to two constructs in different ways. One paper claims a causal relationship from Context utilization to Input regurgitation, stating that regurgitating data can be an outcome of failure in effectively utilizing contexts. Another paper reports that Input regurgitation is related to In-context learning, describing context parroting as a simple mechanism used by foundation models.
