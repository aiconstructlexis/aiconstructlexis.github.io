# FewRel
**Type:** Measurement instrument  
**Supporting papers:** 5  

## State of the Field

**What it is.** Across the papers, FewRel is most commonly described as a benchmark dataset for few-shot relation extraction, used to evaluate model performance in low-resource relation classification scenarios. A recurring variant of this description places it in continual learning settings with limited data. A smaller framing describes it more broadly as a dataset for type discovery that focuses on identifying relation types from text.

**What it is claimed to measure.** Papers use FewRel to evaluate model performance in few-shot relation extraction, especially in low-resource relation classification scenarios and continual learning settings with limited data. Some authors also present it as supporting relation type discovery from text. No construct or behavioral indicator is explicitly linked to it.

**Space of uses.** Most commonly, papers use FewRel alongside TACRED and position it as a benchmark for experiments and baseline comparisons, including paired FCRE benchmark evaluations. A smaller use groups it with FewEvent and FewNerd as information extraction datasets focused on event, entity, and relation type discovery.
