# Logistics
**Type:** Measurement instrument  
**Supporting papers:** 3  

## State of the Field

**What it is.** The prevailing description treats Logistics as a PDDL planning benchmark or domain centered on transporting packages between locations with trucks and airplanes. The definitions are closely aligned: one calls it a classical PDDL planning benchmark, while another describes it as a benchmark planning domain specified in PDDL.

**What it is claimed to measure.** Papers use Logistics to measure one construct, Planning, and it is not linked to any behavioral indicators. The reported use converges on that single construct: papers frame it under planning benchmarks and use it when evaluating simple or valid plan generation in the logistics domain.

**Space of uses.** In practice, papers position Logistics as one task within a broader set of PDDL problems rather than as a standalone instrument. One study includes it among four PDDL tasks, BlocksWorld, Minigrid, Logistics, and Tetris, and another calls it a widely used benchmark when testing whether many-shot in-context learning can improve simple plan generation; no measurement instrument is linked to it.
