# UniGeo
**Type:** Measurement instrument  
**Supporting papers:** 3  

## State of the Field

**What it is.** Across the definition, papers treat UniGeo as a dataset for unified geometry problem solving. In G-LLaVA: Solving Geometric Problem with Multi-Modal Large Language Model, it is also described as a subtask within the MathVista benchmark and is mentioned among more recent datasets.

**Space of uses.** The same paper uses UniGeo as one of the sub-tasks for reporting results on MathVista-GPS multiple-choice questions, which it presents for easier evaluation. In that usage, it appears alongside GeoQA+, Geometry3K, and GEOS.
