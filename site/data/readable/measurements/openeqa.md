# OpenEQA
**Type:** Measurement instrument  
**Supporting papers:** 3  

## State of the Field

**What it is.** In the one definition, OpenEQA is treated as a dataset for Embodied Question Answering that offers "rich scenarios" for the task. It is described as providing instances that include a question, a ground truth answer, and associated episode memory from 3D environments.

**What it is claimed to measure.** The papers do not state that OpenEQA measures any named construct or behavioral indicator. In this literature, it is described as a dataset for the task rather than linked to particular constructs through reported measurement claims.

**Space of uses.** Usage is described narrowly. In "EQA-RM: A Generative Embodied Reward Model with Test-time Scaling," the authors say their dataset construction process "builds upon" OpenEQA, using its question, answer, and episode-memory format as a basis, and they also cite datasets like OpenEQA as offering rich scenarios for the task. No other instruments are described alongside it.
