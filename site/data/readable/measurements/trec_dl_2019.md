# TREC-DL 2019
**Type:** Measurement instrument  
**Supporting papers:** 5  
**Also known as:** TREC-DL19, TREC-DL'19, TREC-DL2019, TREC DL 2019  

## State of the Field

**What it is.** Across the papers, the prevailing description is a benchmark dataset from the TREC Deep Learning Track 2019 for information retrieval evaluation, though one definition presents it as a test set. Descriptions variously emphasize passage retrieval, reranking, document relevance tasks, and deep learning-based ad-hoc retrieval, and one paper notes that it is derived from MS-MARCO-V1 while another highlights human-annotated relevance judgments.

**What it is claimed to measure.** Papers do not explicitly link TREC-DL 2019 to any constructs or behavioral indicators. Instead, they describe it as evaluating passage retrieval systems, information retrieval and reranking tasks, document relevance tasks, and document re-ranking systems, including LLM-based ranking settings.

**Space of uses.** Papers commonly use it alongside TREC-DL 2020 or DL20, and some descriptions place it beside MS MARCO or the BEIR benchmark. It is positioned as an in-domain benchmark in one paper, as one of several widely used benchmarks in another, and as a benchmark used to test LLM-based ranking systems across pairwise, listwise, and setwise paradigms.

## Sources

**TREC-DL19** (1 paper: [REARANK: Reasoning Re-ranking Agent via Reinforcement Learning](https://aclanthology.org/2025.emnlp-main.125.pdf))
> A benchmark dataset from the TREC Deep Learning Track 2019, derived from MS-MARCO-V1, used for in-domain evaluation of information retrieval and reranking tasks.

**TREC-DL'19** (1 paper: [RaDeR: Reasoning-aware Dense Retrieval Models](https://aclanthology.org/2025.emnlp-main.1011.pdf))
> A test set from the TREC Deep Learning Track 2019, used for evaluating passage retrieval systems, often in conjunction with MS MARCO.

**TREC-DL2019** (1 paper: [The Ranking Blind Spot: Decision Hijacking in LLM-based Text Ranking](https://aclanthology.org/2025.emnlp-main.1116.pdf))
> Benchmark dataset from the Text REtrieval Conference used to evaluate LLM-based ranking systems on document relevance tasks, assessing performance in passage retrieval and reranking.

**TREC DL 2019** (1 paper: [REALM: Recursive Relevance Modeling for LLM-based Document Re-Ranking](https://aclanthology.org/2025.emnlp-main.1218.pdf))
> Benchmark dataset for evaluating document re-ranking systems in information retrieval, focusing on deep learning-based ad-hoc retrieval tasks with human-annotated relevance judgments.
