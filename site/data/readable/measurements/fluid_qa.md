# FLUID QA
**Type:** Measurement instrument  
**Supporting papers:** 1  

## State of the Field

A multilingual benchmark that evaluates figurative language usage in multi-turn dialogue across English, Korean, and Chinese, using a cloze-style multiple-choice format to assess pragmatic appropriateness.
