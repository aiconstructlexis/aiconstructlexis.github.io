# HH-RLHF helpful subset
**Type:** Measurement instrument  
**Supporting papers:** 2  
**Also known as:** HH-RLHF-helpful, Anthropic Helpfulness dataset  

## State of the Field

A binary human-preference dataset of helpfulness-oriented response comparisons used to test reward-model explanations.

## Sources

**HH-RLHF-helpful** (1 paper: [Interpreting Language Reward Models via Contrastive Explanations](https://proceedings.iclr.cc/paper_files/paper/2025/file/3538a22cd3ceb8f009cc62b9e535c29f-Paper-Conference.pdf))
> A binary human-preference dataset of helpfulness-oriented response comparisons used to test reward-model explanations.

**Anthropic Helpfulness dataset** (1 paper: [InfAlign: Inference-aware language model alignment](https://raw.githubusercontent.com/mlresearch/v267/main/assets/balashankar25a/balashankar25a.pdf))
> A dataset consisting of multi-turn dialogues between a human and a digital assistant, with human preference labels indicating which of two responses is more helpful.
