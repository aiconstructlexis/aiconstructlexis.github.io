## State of the Field

**What it is.** Across the usage in the papers, ETHOS is described as a dataset for detecting hate speech. The only definition further presents it as a binary classification benchmark on which papers report F1 score under optimized prompts.

**What it is claimed to measure.** The papers here use ETHOS for hate-speech detection evaluation via F1 in binary classification. No papers link it to any constructs or behavioral indicators.

**Space of uses.** In the only described usage, ETHOS is reported alongside ArSarcasm, Liar, and BBH-navigate, with F1 used as the evaluation metric in the same setup.
