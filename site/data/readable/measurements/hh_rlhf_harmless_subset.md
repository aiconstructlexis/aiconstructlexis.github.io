# HH-RLHF harmless subset
**Type:** Measurement instrument  
**Supporting papers:** 2  
**Also known as:** HH-RLHF-harmless, Anthropic Harmlessness dataset  

## State of the Field

A binary human-preference dataset of harmlessness-oriented response comparisons used to test reward-model explanations.

## Sources

**HH-RLHF-harmless** (1 paper: [Interpreting Language Reward Models via Contrastive Explanations](https://proceedings.iclr.cc/paper_files/paper/2025/file/3538a22cd3ceb8f009cc62b9e535c29f-Paper-Conference.pdf))
