# ConflictingQA
**Type:** Measurement instrument  
**Supporting papers:** 2  
**Also known as:** CONFLICTINGQA  

## State of the Field

Benchmark dataset containing controversial yes/no web search queries and labeled support/refute web pages, used to evaluate model performance on debatable query summarization.

## Sources

**ConflictingQA** (1 paper: [MoDS: Moderating a Mixture of Document Speakers to Summarize Debatable Queries in Document Collections](https://aclanthology.org/2025.naacl-long.20.pdf))
> Benchmark dataset containing controversial yes/no web search queries and labeled support/refute web pages, used to evaluate model performance on debatable query summarization.

**CONFLICTINGQA** (1 paper: [From Distributional to Overton Pluralism: Investigating Large Language Model Alignment](https://aclanthology.org/2025.naacl-long.346.pdf))
> Dataset of short questions on controversial topics where high-quality responses provide context and elaboration, used to evaluate stance diversity and pluralism in LLM responses.
