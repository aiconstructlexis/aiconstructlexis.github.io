# CASIE
**Type:** Measurement instrument  
**Supporting papers:** 4  

## State of the Field

**What it is.** Across the papers, CASIE is most commonly described as a cybersecurity event extraction or event detection dataset. Definitions converge on its focus on cybersecurity incidents and on a five-event-type schema, often named as Databreach, Phishing, Ransom, Discover, and Patch; some descriptions also note trigger and argument annotations, while others frame it as identifying security-related incidents from technical reports and news or as evaluating event detection in cyber threat reports.

**What it is claimed to measure.** Across these papers, CASIE is presented as a benchmark dataset rather than as an instrument explicitly said to measure a named construct or behavioral indicator. No papers link it to any constructs or behavioral indicators, so the descriptions emphasize task evaluation instead of an explicit measurement claim.

**Space of uses.** Papers use CASIE in experiments on event extraction and event detection, and one study places it within a broader benchmark suite by reporting results on "16 IE benchmarks" (Label Drop for Multi-Aspect Relation Modeling in Universal Information Extraction). No other measurement instrument is linked to it, so the papers present it without a stated paired benchmark.
