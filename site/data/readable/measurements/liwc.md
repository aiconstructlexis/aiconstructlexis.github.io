# LIWC
**Type:** Measurement instrument  
**Supporting papers:** 5  
**Also known as:** LIWC-22  

## State of the Field

**What it is.** Across the papers, LIWC is treated as a text analysis and psycholinguistic feature extraction tool. The prevailing description is that it categorizes words into linguistic and psychological dimensions, including emotion, cognition, and formality, and one paper specifies the LIWC-22 version as calculating the percentage of words in a text that fall into different linguistic and psychological categories.

**What it is claimed to measure.** No construct or behavioral indicator is explicitly linked to LIWC in these papers. Instead, papers describe it more generally as providing psycholinguistic characteristics and category-based linguistic outputs, including outputs used to build trait-specific linguistic features.

**Space of uses.** Papers use LIWC as an analysis tool over text and responses. One usage reports segment comparison with LIWC features alongside WritePrint features, while another analyzes responses with LIWC-22 and constructs trait-specific linguistic features from its outputs.
