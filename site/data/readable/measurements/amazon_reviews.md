## State of the Field

**What it is.** Across the surveyed work, Amazon Reviews is treated as a product review dataset, most commonly described as Amazon reviews across multiple categories. One use presents it as a sentiment analysis dataset for evaluating model performance on commercial user feedback, while another describes the public Amazon Reviews dataset as adapted with simulated user consultation texts, user profiles, and interaction behaviors for evaluation. In a separate experimental description, the Amazon product reviews are also said to be labeled into a three-layer taxonomy DAG.

**What it is claimed to measure.** Papers link Amazon Reviews to one behavioral indicator and no constructs. The reported measurement claim is concentrated on hierarchical text classification: papers use it to measure that indicator, with one description specifying Amazon product reviews labeled into a three-layer taxonomy DAG rather than spreading the instrument across several reported constructs or behaviors.

**Space of uses.** No other measurement instrument is linked to Amazon Reviews. In the papers, it is used as a task dataset for sentiment analysis, as a public dataset adapted for evaluation with simulated user consultation texts, user profiles, and interaction behaviors, and as one of the public datasets used in experiments on hierarchical text classification.
