# DBpedia Class
**Type:** Measurement instrument  
**Supporting papers:** 2  
**Also known as:** DBpedia Class dataset, Dbpedia Class  

## State of the Field

A dataset used to examine watermark decryption accuracy by analyzing word frequencies within specific semantic classes.
